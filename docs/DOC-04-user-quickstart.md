# DOC-04 User quickstart

## 1. What the app does

Watt's Up? is a 3D house that shows what each appliance costs you every month. It also lets you practise a power cut: your inverter can run only 3 appliances, so you choose which.

## 2. What to do

1. Press the button on the intro screen to enter the house.
2. Click an appliance in the list or in the 3D house. Switch it on or off and change its daily hours.
3. Use the Target bill slider to set what you want to spend.
4. Press **Power Cut**, pick exactly 3 appliances, then press **Confirm**.

Use the Villa / Rooms toggle in the top bar: Villa shows the real house from the front, Rooms is where you click appliances.

## 3. What to expect

- The bill changes instantly when you switch an appliance or change its hours.
- The target panel says how many rupees you are under or over target.
- In a Power Cut the screen flickers first. A 4th pick shows "Inverter can only run 3 appliances".
- The result card shows comfort, backup time and cost per hour, plus the best possible combination.

## 4. If you make a mistake

| Problem | Fix |
|---|---|
| Want your old switches back after a power cut | Press **Restore power** |
| Chose the wrong 3 appliances | Press **Try again** |
| Stuck in a room view | Press **Back to overview**, or **Esc** |
| Open card in the way | Press **Esc** to close it |
| Everything is confusing | Reload the page; all values return to the defaults |
